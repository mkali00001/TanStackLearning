# TanStack Learning

A project for learning TanStack libraries and modern React data fetching patterns.

## Project Structure

- **src/pages/FetchOld.jsx**: Demonstrates traditional data fetching using `useEffect` and `useState`.
- **src/pages/FetchRq.jsx**: Demonstrates data fetching using TanStack Query (React Query) with pagination.

## Tech Stack

- React
- Vite
- TanStack Query
- Axios
- React Router DOM
