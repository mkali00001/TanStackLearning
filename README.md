# TanStack Learning

A project for learning TanStack libraries and modern React data fetching patterns.

## Features

- **Data Fetching Comparison**: Examples of both traditional `useEffect` and modern TanStack Query approaches.
- **Pagination**: Implementation of paginated data fetching.
- **UX Improvements**: Usage of `keepPreviousData` to prevent layout shift during data loading.

## Project Structure

- **src/pages/FetchOld.jsx**: Demonstrates traditional data fetching using `useEffect` and `useState`.
- **src/pages/FetchRq.jsx**: Demonstrates data fetching using TanStack Query (React Query) with pagination and `keepPreviousData`.

## Tech Stack

- React
- Vite
- TanStack Query
- Axios
- React Router DOM

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```
